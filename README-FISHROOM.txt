MY FISH ROOM — TEST UPGRADE

IMPORTANT: Do not delete your existing GitHub version or clear Safari data.
This package is a TEST version, not yet installed on your live website.

New features: dashboard, quick actions, breeding history and automatic fry ages,
water-test alerts, equipment tracking, expanded tank history, voice questions,
cloud saving status and optional Supabase saving. Original 2D layout retained.

CLOUD SETUP:
1. Open the upgraded app under your existing GitHub website origin (after a
   separate backup and carefully staged deployment) so existing local records
   are available. Opening an HTML file locally may show different data.
2. In Settings, enter your Supabase Project URL (https://PROJECT.supabase.co).
3. The public publishable key is prefilled. Sign in using the Supabase Auth user.
4. Verify the current stock counts and water-change history in THIS browser.
5. Choose Upload CURRENT records. Only then does cloud auto-saving switch on.
6. Reopening the page requires signing in again; automatic cloud saving is OFF
   until sign-in and activation. Local saving continues regardless.

IMPORTANT LIMITATIONS:
- No live deployment or cloud upload has been performed.
- Cloud saving needs the exact Supabase Project URL and a successful login.
- This test build has not been browser-tested on the user's iPhone.
- Offline changes save locally but are not automatically retried until the next
  successful save with cloud enabled. Avoid relying on cloud as sole backup.
- Supabase user authentication and row-level security provide privacy; the
  original app's front-end password gate alone is not secure access control.
